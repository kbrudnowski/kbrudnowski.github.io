3 City Cafe & WiFi

The Tri-City Cafes with WiFi web app is a django-built comprehensive platform designed to assist users in discovering cafes with WiFi access in the Tri-City area of Poland.

One of the standout features of the web app is the ability for logged-in users to contribute to the community by adding new cafes to the list. By allowing users to share their knowledge and experiences, the app ensures that the list remains comprehensive and up to date. Additionally, staff-users can also delete existing cafes.

Financial Data Scrapper

An automated EBITDA calculator that unveils hidden financial insights for companies listed in the esteemed WIG20 index. Despite the EBITDA metric being available only to premium users, my in-depth knowledge of financial calculations enabled me to create a dynamic Python program that intelligently retrieves other relevant data and accurately calculates EBITDA which may be later saved in any desired format.

Watermark Me

A simple desktop application built with Tkinter that automates the process of adding watermarks to all your photos. It provides an intuitive interface where you can select an image file, preview it, apply a customizable watermark, and save the watermarked image.

TypeMaster

This is a typing speed test application designed to enhance users' typing skills and accuracy. The app offers a wide range of randomly generated sample texts, ensuring a fresh and challenging typing experience with every session. Users can test their typing speed by entering the sample text provided and receive instant feedback on their performance. The application calculates the user's words per minute (WPM) and highlights any errors, allowing users to identify and correct mistakes as they type. TypeMaster includes a high score tracking feature that enables users to monitor their progress and strive for personal improvement. By keeping track of their best WPM achieved, users can set goals and track their typing speed development over time.

Blank Page

This website is a unique online text editor designed to tackle writer's block. It presents a blank page with a message encouraging users to keep writing continuously without stopping. The twist is that if the user pauses for more than 5 seconds, all their progress will be erased. A timer counts down, and any lack of input triggers the deletion of the written content, making it an interesting challenge to maintain a continuous flow of writing. The site seems to be a playful and fun experiment, emphasizing the importance of consistent writing and overcoming writer's block.

Now-casting Economic Indicators

This project aimed to predict an economic indicator using carefully selected parameters, employing non-linear machine learning methods to address complex relationships between variables. I diligently preprocessed the dataset, handling missing values, normalizing data, and selecting features to ensure optimal model training. By experimenting with various regression algorithms, including linear regression, ensemble learning, and support vector regression, I evaluated their performance using the R-squared metric. The most efficient models were identified. Throughout the project, I utilized Python's popular machine learning libraries, scikit-learn, and Keras, for model development, evaluation, and fine-tuning.
